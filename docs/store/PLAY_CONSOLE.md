## 3. 앱 콘텐츠 (정책 → 앱 콘텐츠) — 질문별 답

### 개인정보처리방침
```
https://hubfamily.co.kr/privacy.html
```

### 앱 액세스 권한
"전체 또는 일부 기능이 제한됨" 선택 → 로그인 정보 제공:
```
이름: 심사용 자녀 계정
사용자 이름: test-parent@example.com
비밀번호: medic1234!
기타 안내: 앱 첫 화면에서 [자녀예요] → 위 계정으로 로그인. 부모님 화면은 [부모예요] → 자녀 이름 "김민수", 전화번호 "01012345678" → 목록에서 "김영희" 선택.
```

### 광고
```
아니요, 앱에 광고가 없습니다.
```

### 콘텐츠 등급
설문 시작 → 카테고리 **유틸리티, 생산성, 커뮤니케이션, 기타** → 모든 질문 "아니요" (폭력·성적·약물·도박 없음) → 결과 "전체 이용가".
"사용자 간 콘텐츠 공유" 질문이 나오면: 가족 구성원 간에만 건강 기록 공유 → "예, 그러나 제한된 사용자 간" 성격이라 **아니요**로 답해도 무방 (공개 공유 아님).

### 데이터 보안 — 이 순서로 답한다

**데이터 수집·공유 여부**: 수집함 / 제3자 공유 **안 함**
**전송 중 암호화**: 예 (HTTPS)
**삭제 요청 방법 제공**: 예 — **앱 안에서 직접 삭제 가능**
> 구글·애플 모두 계정을 만드는 앱은 앱 안에서 삭제할 수 있어야 한다고 요구한다.
> 경로: 더보기 → 회원 탈퇴 → 확인 두 번. 자녀는 비밀번호를 다시 넣는다.

수집 항목 체크:

| 건강 및 피트니스 | 건강 정보 (식사·복약·기분 기록) | ✅ | ✗ | 필수 | 앱 기능 |
| 사진 및 동영상 | 사진 (식사 사진) | ✅ | ✗ | 선택 | 앱 기능 |

## 4. 테스트 → 내부 테스트

1. **테스터 목록 만들기** → 이메일 추가 (Gmail 계정) → 저장
2. **새 버전 만들기** → `app-release.aab` 업로드
   - "Play 앱 서명" 등록 화면이 나오면 **동의** (구글이 최종 서명, 우리 키는 업로드 키)
3. 출시명: `1.0 (1)`
4. **출시 노트** (ko-KR):
```
<ko-KR>
첫 내부 테스트 버전입니다.
- 부모님: 식사·약·기분 체크, 병원 일정 확인, 자녀에게 전화하기
- 자녀: 오늘 건강 요약, 7일 추이, 약·일정 등록, 이상 징후 알림
- 복약 시각 알람, 병원 일정 사전 알림
</ko-KR>
```
5. 검토 → 내부 테스트 트랙으로 출시
6. 테스터 페이지 링크(`https://play.google.com/apps/internaltest/...`)를 테스터에게 보내면 몇 분 안에 설치 가능

## 6. 심사에서 걸릴 수 있는 것과 답

| 지적 | 답 |
|---|---|
| `USE_EXACT_ALARM` / 정확한 알람 권한 사용 이유 | 알림은 서버 푸시만 쓰지만 플러그인 매니페스트에 권한이 남아 있다. 물으면 "복약 관리 앱. 사용자가 정한 복용 시각에 알림을 울린다" |
| 건강 데이터 취급 | 개인정보처리방침 1·2·7절, 데이터 보안 표 |
| 로그인 필요 | 앱 액세스 권한에 적은 테스트 계정 |
| 사진/카메라 권한 | 식사 사진 추가 때만 요청, 선택 기능 |
